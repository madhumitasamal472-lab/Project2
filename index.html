SyncDoc Technical Specification
Collaborative Document Engine with AST Conflict Resolution
SyncDoc is a collaborative document engine designed to prevent destructive overwrites when multiple users edit the same structured document simultaneously.
Instead of treating a document as plain text, SyncDoc represents every document as an Abstract Syntax Tree (AST). This allows individual structural blocks to be synchronized independently.
User B The synchronization engine uses a CRDT-based architecture to merge concurrent changes while preserving the work performed by every collaborator.

System Architecture

  • AST Database using Express and MongoDB
  • WebSocket synchronization layer
  • Yjs CRDT collaboration engine
  • React block-based editor interface
  • DOMPurify security pipeline
JavaScript const syncDocument = (change) => { const astNode = documentAST.find( node => node.id === change.nodeId ); return resolveConflict(astNode, change); };
User A Each AST node receives a unique identifier, allowing the synchronization layer to determine exactly which part of the document has changed.

Conflict Resolution

When two users modify different blocks, both changes are merged automatically. If the same node is modified concurrently, the CRDT matrix determines a deterministic conflict-free result.
